These programs depend on the following libraries: NumPy, pandas, seaborn, matplotlib.pyplot, SeqIO from Biopython, the parser module from Pyteomics, and DeepLC from the deeplc package. The digestLab program parses a Methanococcus proteome FASTA file and digests each protein into individual tryptic peptides using Pyteomics. It then calculates the percentage of peptide uniqueness across the dataset and plots peptide length distributions grouped by uniqueness. The program then runs the next file: pepML, which uses DeepLC to apply a machine learning model to the generated peptides in order to predict retention times. Only the digestLab file needs to be run; as mentioned before it runs the pepML file automatically
