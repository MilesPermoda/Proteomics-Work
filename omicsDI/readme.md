This program requires four libraries: requests, pandas, seaborn, and matplotlib.pyplot. It uses the requests library to fetch multiple proteomic datasets from the omicsDI website for three species (Methanococcus maripaludis, Shewanella oneidensis,and Bacillus amyloliquefaciens), and then graphs the number of occurrences of both the database of origin as well as the year of publication of all datasets grouped by species.
